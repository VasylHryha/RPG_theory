# RRG v0.2 — Research audit and worked checks

**30 September 2026**

This package re-evaluates Recursive Resonant Geometry against identifiable research in physics, reaction-network chemistry, biological replication, mathematical coarse-graining, neuroscience and physical AI.

It preserves the original meaning of geometry and full temporal mode structure. It separates that useful organizing viewpoint from claims that all forces or all persistent structures have already been derived from it.

## Read in order

1. `01_research_audit.md` — findings, scope and corrections to v0.1b.
2. `02_mathematical_results.md` — worked geometry–mode feedback, exact recursive response reduction, stability and chemical examples.
3. `03_next_experiment.md` — falsifiable next test with budgets and failure criteria.
4. `SOURCES.md` — primary papers/institutional sources and what was actually checked.

## Executed checks

`verify_response_closure.py` produced `verification_results.json` and `response_errors.csv`.

Run with Python 3.10+ and NumPy:

```bash
python verify_response_closure.py
```

The calculation verifies repeated reduction of a specified eight-site linear oscillator network. Exact interface-response errors are on the order of 10^-15. Sixteen randomly perturbed network controls are included. A separate adiabatic cavity/spring example solves a local geometry–mode feedback condition.

These are numerical checks of restricted effective models and known block algebra. They are **not** spontaneous hierarchy formation, a newly established universal invariant, a biological experiment, a new particle theory, or an AI benchmark.

## Main outcome

The next higher-level unit should preserve the relevant **response**, including internal modes and memory where needed. A single average phase is not a general substitute for a composite structure.

Repeated coarse-graining already has rigorous mathematical precedents. The distinctive research task is to discover useful units automatically and preserve predictive accuracy at lower cost across different systems.

## What changed from earlier claims

- Self-consistency was separated from dynamical stability.
- Potential/free energy was separated from effective action.
- “Same little equation at every scale” was replaced with an explicit predictive closure test.
- Internal dynamics and memory were retained rather than discarded by averaging.
- Chemical organizational closure was connected to existing theory, with its assumptions.
- Spectral-action and force-unification claims were narrowed to what their sources establish.
- Recurrence, copying and formation remain related abstractly but have distinct measurable production mechanisms.

Original v0.1b files were left unchanged. `PROVENANCE.json` records input hashes and output hashes. The source register does not retroactively verify every citation made in earlier conversation turns.
