# 0. What this document can and cannot prove

There are two very different meanings of “prove the theory”.

## 0.1 What can be proved now

We can prove, inside a clearly stated class of nonlinear stochastic pattern-forming systems, that:

1. a fluctuating background can nucleate a finite-amplitude persistent mode;
2. the persistent mode has a selected characteristic spatial scale;
3. the stable mode can modify a slower background variable;
4. that background modification can make a previously stable/inaccessible collective mode unstable/accessible;
5. under an explicit monotonic spectral condition, the newly accessible mode has a larger characteristic scale;
6. if a coarse-graining map approximately preserves the equation family, the recursion error across levels obeys a quantitative bound.

Those statements are mathematical claims and are proved below.

## 0.2 What this does **not** prove

It does **not** prove that:

- the real primordial universe is governed by the specific toy PDE below;
- every physical scale is generated by this mechanism;
- the Standard Model or general relativity has been derived;
- physical spacetime expansion is caused by recursive resonant organization;
- the universe must always become larger or more complex;
- every stable resonance expands.

Those are higher RRG claims. The value of the model is that it turns them into sharper mathematical questions instead of leaving them as metaphors.

# 2. Minimal Recursive Background Field model

Let \(u(x,t)\in\mathbb R\) be a fast pattern field and \(B(x,t)\in\mathbb R\) a slower coarse background.

We propose the model class

\[
\boxed{
\partial_t u
=
r(B)u
-\left[q(B)^2+\nabla^2\right]^2u
+\nu_3u^3
-\nu_5u^5
+\sqrt{2D}\,\xi(x,t)
}
\tag{2.1}
\]

with

\[
\boxed{
\tau_B\partial_t B
=
D_B\nabla^2B
-\left(B-B_n\right)
+\rho\,\mathcal C_\ell[u^2]
}
\tag{2.2}
\]

where:

- \(r(B)\) is a background-dependent instability/control parameter;
- \(q(B)>0\) is the preferred wavenumber;
- \(2\pi/q(B)\) is the corresponding characteristic length;
- \(\nu_3>0\) and \(\nu_5>0\) permit a subcritical finite-amplitude branch;
- \(D\ge 0\) is noise intensity;
- \(\xi\) is idealized zero-mean noise;
- \(\mathcal C_\ell\) is coarse-graining over a length larger than a carrier wavelength but smaller than the next level;
- \(\rho>0\) measures backreaction of persistent pattern intensity on the background;
- \(B_n\) is the inherited level-\(n\) background.

This is **not** asserted to be the fundamental equation of nature. It is the smallest explicit model we use to test whether the proposed logical chain is mathematically coherent.

# 3. Theorem 1 — the background selects a characteristic mode

Fix a spatially uniform background \(B\) and linearize (2.1) about \(u=0\), ignoring noise.

For a Fourier perturbation

\[
u_k(x,t)=\hat u_k e^{ikx+\lambda t},
\]

we obtain

\[
\boxed{
\lambda(k;B)
=
r(B)-\left[q(B)^2-k^2\right]^2.
}
\tag{3.1}
\]

## Theorem 1

For any fixed \(B\) with \(q(B)>0\), the maximum linear growth rate occurs at

\[
\boxed{|k|=q(B)}
\]

and equals

\[
\boxed{\lambda_{\max}(B)=r(B)}.
\]

Therefore the background selects the characteristic wavelength

\[
\boxed{L(B)=\frac{2\pi}{q(B)}}.
\]

### Proof

Because

\[
\left[q(B)^2-k^2\right]^2\ge0,
\]

its minimum is zero, obtained exactly at \(k^2=q(B)^2\). Hence \(\lambda\) is maximized at \(|k|=q(B)\), where \(\lambda=r(B)\). QED.

## Interpretation

This is the precise mathematical form of

\[
\boxed{
B\rightarrow \text{allowed/preferred mode}\rightarrow\text{characteristic geometry}.
}
\]

It also immediately gives a failure condition: if \(q(B)\) does not shift with the background, recursive background change does not automatically create a new characteristic spatial scale.

# 4. Weakly nonlinear reduction: a finite-amplitude resonator

Near a finite-wavelength instability, the pattern field can be expanded around its critical mode. Schematically,

\[
 u(x,t)
\approx
A(X,T)e^{iqx}+\bar A(X,T)e^{-iqx}+\text{higher harmonics},
\]

with slow variables

\[
X=\varepsilon x,
\qquad
T=\varepsilon^2t.
\]

For a subcritical pattern-forming regime, the local amplitude dynamics can be written in the real radial amplitude \(a=|A|\) as

\[
\boxed{
\dot a
=
\mu a+c_3a^3-c_5a^5,
\qquad
c_3,c_5>0.
}
\tag{4.1}
\]

The same cubic–quintic normal form occurs broadly near subcritical pattern-forming bifurcations. The exact coefficients depend on the microscopic model.

# 5. Theorem 2 — a stable resonator can coexist with the noisy background

Define

\[
f(a)=\mu a+c_3a^3-c_5a^5.
\]

Nonzero equilibria satisfy

\[
\mu+c_3a^2-c_5a^4=0.
\]

Let \(y=a^2\). Then

\[
 c_5y^2-c_3y-\mu=0,
\]

so

\[
\boxed{
 y_\pm
=
\frac{c_3\pm\sqrt{c_3^2+4c_5\mu}}{2c_5}.
}
\tag{5.1}
\]

## Theorem 2

If

\[
\boxed{
-\frac{c_3^2}{4c_5}<\mu<0,
}
\tag{5.2}
\]

then:

1. \(a=0\) is linearly stable;
2. \(a_-=\sqrt{y_-}\) is unstable;
3. \(a_+=\sqrt{y_+}\) is stable.

Thus an unstructured state and a finite-amplitude patterned/resonant state coexist.

### Proof

At \(a=0\),

\[
f'(0)=\mu<0,
\]

so zero is stable.

At a nonzero equilibrium with \(y=a^2\), use

\[
\mu=-c_3y+c_5y^2
\]

inside

\[
f'(a)=\mu+3c_3a^2-5c_5a^4.
\]

This gives

\[
\boxed{
f'(a)=2y(c_3-2c_5y).
}
\tag{5.3}
\]

The two roots obey

\[
y_-<\frac{c_3}{2c_5}<y_+.
\]

Therefore \(f'(a_-)>0\), so \(a_-\) is unstable, while \(f'(a_+)<0\), so \(a_+\) is stable. QED.

## Meaning for RRG

The system does not need an instruction saying “become an object”.

It has two attractors:

\[
\boxed{
\text{background state}
\qquad\text{and}\qquad
\text{finite-amplitude resonant state}.
}
\]

A sufficiently large fluctuation can move the system from the first basin to the second.

# 6. Theorem 3 — noise can nucleate the persistent state

Add amplitude noise:

\[
\boxed{
da
=
\left(\mu a+c_3a^3-c_5a^5\right)dt
+\sqrt{2D_A}\,dW_t.
}
\tag{6.1}
\]

Define the potential

\[
\boxed{
V(a)
=
-\frac{\mu}{2}a^2
-\frac{c_3}{4}a^4
+\frac{c_5}{6}a^6.
}
\tag{6.2}
\]

Then

\[
 da=-V'(a)dt+\sqrt{2D_A}\,dW_t.
\]

For the bistable regime in Theorem 2, \(a=0\) and \(a=\pm a_+\) are local minima of \(V\), separated by barriers at \(a=\pm a_-\).

## Theorem 3

For every nonzero additive noise intensity \(D_A>0\), transitions from the basin around \(a=0\) across the finite barrier have nonzero probability. For the gradient diffusion on a confining domain, the stationary density is proportional to

\[
\boxed{
p_\mathrm{st}(a)
\propto
\exp\!\left[-\frac{V(a)}{D_A}\right].
}
\tag{6.3}
\]

For small noise, the mean transition time is exponentially controlled by the barrier

\[
\Delta V=V(a_-)-V(0),
\]

with Kramers-type scaling

\[
\boxed{
\mathbb E[T_\mathrm{nuc}]
\asymp
C\exp\!\left(\frac{\Delta V}{D_A}\right).
}
\tag{6.4}
\]

### Interpretation

This gives a mathematically standard version of the intuitive statement

\[
\boxed{
\text{noise/fluctuations}
\rightarrow
\text{rare threshold crossing}
\rightarrow
\text{persistent structure}.
}
\]

The crucial point is that noise does **not** manufacture stability. The deterministic nonlinear landscape already contains a stable finite-amplitude state. Noise supplies a route into its basin.

This distinction is essential for the source model.

# 7. Theorem 4 — the persistent resonator changes the background

Suppose the patterned state has settled to a statistically stationary coarse-grained intensity

\[
I_*=\mathcal C_\ell[u^2]>0.
\]

Ignore background diffusion inside a homogeneous region. Equation (2.2) becomes

\[
\boxed{
\tau_B\dot B
=-(B-B_n)+\rho I_*.
}
\tag{7.1}
\]

## Theorem 4

The background converges exponentially to

\[
\boxed{
B_{n+1}=B_n+\rho I_*.
}
\tag{7.2}
\]

If \(B(0)=B_n\), then

\[
\boxed{
B(t)=B_n+\rho I_*\left(1-e^{-t/\tau_B}\right).
}
\tag{7.3}
\]

### Proof

Equation (7.1) is a first-order linear ODE. Solving it gives (7.3), and the \(t\to\infty\) limit is (7.2). QED.

## RRG meaning

This is the first exact closure of the source-direction loop:

\[
\boxed{
R_n\rightarrow B_{n+1}.
}
\]

A persistent resonator is not merely an object sitting inside an unchanged environment. Its time-averaged intensity contributes to the effective environment inherited by subsequent dynamics.

# 8. Theorem 5 — a previous resonator can open a previously inaccessible mode

Let a candidate collective channel \(j\) have the linear dispersion

\[
\boxed{
\lambda_j(k;B)
=
r_j+\alpha_j(B-B_n)
-\left[q_j(B)^2-k^2\right]^2,
\qquad \alpha_j>0.
}
\tag{8.1}
\]

Before the level-\(n\) resonator exists, suppose

\[
r_j<0.
\]

Then the candidate mode is linearly damped at \(B=B_n\).

After the resonator modifies the background by

\[
\Delta B=\rho I_*,
\]

the maximum growth rate becomes

\[
\Lambda_j(B_{n+1})
=
r_j+\alpha_j\rho I_*.
\]

## Theorem 5

The previously inaccessible mode becomes linearly unstable if and only if

\[
\boxed{
\alpha_j\rho I_*>-r_j.
}
\tag{8.2}
\]

### Proof

By Theorem 1, the maximum growth rate occurs at \(|k|=q_j(B)\), so the square term vanishes. The mode is unstable exactly when the remaining coefficient is positive:

\[
r_j+\alpha_j\rho I_*>0.
\]

Rearranging gives (8.2). QED.

## Interpretation

This is the cleanest mathematical statement in the current source model:

\[
\boxed{
\text{structure at level }n
\rightarrow
\text{background shift}
\rightarrow
\text{new mode becomes possible at level }n+1.
}
\]

No claim about biology, cosmology, or fundamental forces is needed to prove this mechanism inside the model.

# 9. Theorem 6 — exact condition for scale growth

The characteristic wavelength of the candidate mode is

\[
L(B)=\frac{2\pi}{q(B)}.
\]

## Theorem 6A — general monotonic form

If

\[
\boxed{q'(B)<0}
\tag{9.1}
\]

through the relevant interval and the previous resonator increases the background,

\[
B_{n+1}>B_n,
\]

then

\[
\boxed{L(B_{n+1})>L(B_n).}
\tag{9.2}
\]

### Proof

Since

\[
L(B)=2\pi/q(B),
\]

we have

\[
L'(B)
=-\frac{2\pi q'(B)}{q(B)^2}.
\]

Because \(q(B)^2>0\) and \(q'(B)<0\), \(L'(B)>0\). Thus increasing \(B\) increases \(L\). QED.

## Theorem 6B — exponential example

If

\[
\boxed{
q(B)=q_0e^{-\sigma B},
\qquad \sigma>0,
}
\tag{9.3}
\]

then one recursive background increment \(\Delta B_n=\rho I_n\) gives

\[
\boxed{
\frac{L_{n+1}}{L_n}
=e^{\sigma\rho I_n}>1.
}
\tag{9.4}
\]

If every realized level satisfies

\[
I_n\ge I_{\min}>0,
\]

then

\[
\boxed{
L_N
\ge
L_0e^{N\sigma\rho I_{\min}}.
}
\tag{9.5}
\]

### Importance

This is the exact mathematical point where the claim “the hierarchy always grows to larger scales” either succeeds or fails.

It is **not automatic from resonance alone**.

A theory that wants monotonic scale growth must derive something equivalent to

\[
q'(B)<0
\]

from deeper dynamics.

If instead \(q'(B)>0\), the recursive mode becomes smaller-scale. If \(q'(B)=0\), no new characteristic size is generated by this mechanism.

This is therefore a powerful falsification condition, not a cosmetic detail.

# 10. Time required to create the next background

From (7.3), define the fraction \(0<p<1\) of the asymptotic background shift that must be reached before the next mode crosses its threshold.

If

\[
B_\mathrm{crit}-B_n=p\rho I_*,
\]

then

\[
p=1-e^{-t_\mathrm{open}/\tau_B},
\]

so

\[
\boxed{
t_\mathrm{open}
=-\tau_B\ln(1-p).
}
\tag{10.1}
\]

Thus a new level has an intrinsic formation time even after its parent resonator exists.

This formalizes the intuition that larger/higher organization can require both new scale and additional time.

# 11. Proposition — persistence increases opportunity, not certainty

Suppose a resonator remains active for a lifetime \(T_R\), while the mean nucleation time for the next structure is \(T_\mathrm{nuc}\).

For an approximately Poisson nucleation process with rate \(\kappa=1/T_\mathrm{nuc}\), the probability that at least one successful nucleation occurs during the parent lifetime is

\[
\boxed{
P_\mathrm{next}
=1-e^{-T_R/T_\mathrm{nuc}}.
}
\tag{11.1}
\]

Therefore

\[
\frac{\partial P_\mathrm{next}}{\partial T_R}>0.
\]

A longer-lived resonator has more opportunity to seed the next transition, but persistence alone does not guarantee propagation.

This is a mathematically cleaner version of the intuitive statement “more stable structures can influence farther/longer.”

Let

\[
\Phi_\theta^t
\]

be the microscopic/effective time evolution for parameters \(\theta\), and let

\mathcal R

be the coarse-graining/promotion map that replaces a persistent lower-level structure by an effective higher-level variable.

\Theta:\theta_n\mapsto\theta_{n+1}.

The one-step RRG closure error is

\boxed{
\left\|
\mathcal R\Phi_{\theta_n}^{t}(x)
-
\Phi_{\Theta(\theta_n)}^{\alpha_n t}\mathcal R(x)
\right\|
\le\varepsilon_n.

\tag{12.1}
\]

This is the precise version of

\boxed{
\mathcal R\circ F_n

# 13. Theorem 7 — bound on accumulated recursion error

Assume:

1. the one-step closure error is bounded by \(\varepsilon\) at every level;
2. the effective higher-level evolution is \(K\)-Lipschitz on the relevant attractor/background;
3. \(e_n\) is the mismatch after \(n\) recursive promotions.

Then

\[
\boxed{
e_{n+1}\le \varepsilon+Ke_n.
}
\tag{13.1}
\]

with \(e_0=0\).

## Theorem 7

After \(N\) levels,

\[
\boxed{
e_N
\le
\varepsilon\sum_{j=0}^{N-1}K^j.
}
\tag{13.2}
\]

Therefore:

### If \(K<1\)

\[
\boxed{
e_N\le\frac{\varepsilon}{1-K}.}
\tag{13.3}
\]

The recursion error remains uniformly bounded.

### If \(K=1\)

\[
\boxed{e_N\le N\varepsilon.}
\tag{13.4}
\]

The error grows at most linearly.

### If \(K>1\)

\[
\boxed{
e_N
\le
\varepsilon\frac{K^N-1}{K-1},
}
\tag{13.5}
\]

so small one-step errors can blow up exponentially with recursion depth.

### Proof

Starting from (13.1), repeated substitution gives

\[
e_N
\le
\varepsilon+K\varepsilon+K^2\varepsilon+\cdots+K^{N-1}\varepsilon.
\]

This is the geometric sum in (13.2); (13.3)–(13.5) follow directly. QED.

## Why this matters

This theorem provides a hard quantitative criterion for the universal-recursion program.

A model that looks qualitatively similar at two levels is not enough.

We need:

- a measurable \(\mathcal R\),
- a parameter map \(\Theta\),
- a one-step prediction error \(\varepsilon\),
- a stability/Lipschitz factor \(K\),
- and evidence that the error does not explode as levels are repeated.

That turns “same principle at every scale” into an actual mathematical test.

# 14. Why amplitude equations are important evidence for this program

Pattern-formation mathematics already contains a rigorous version of one crucial RRG move:

\[
\boxed{
\text{fast microscopic pattern}
\rightarrow
\text{slow collective amplitude field}.
}
\]

Near a finite-wavelength instability, the Swift–Hohenberg equation has solutions approximated by

\[
u(x,t)
\approx
\varepsilon A(X,T)e^{ik_0x}+\text{c.c.},
\]

where

\[
X=\varepsilon x,
\qquad
T=\varepsilon^2t,
\]

and \(A\) obeys a Ginzburg–Landau-type amplitude equation.

This is not merely heuristic. Rigorous approximation theorems exist, including recent results for periodically heterogeneous Swift–Hohenberg systems and for stochastic higher-dimensional Swift–Hohenberg equations.

The conceptual relevance is:

> The lower-level carrier oscillation can become “integrated out”, while its slowly varying collective amplitude becomes the effective variable of a larger/slower description.

This is very close to the RRG statement that organized lower-level dynamics becomes the effective background/degree of freedom of the next level.

It does **not** by itself prove indefinite recursion. But it establishes that the key mathematical operation is standard and rigorous in nontrivial physical PDEs.

# 16. Possibility-space growth: what can actually be proved

RRG often uses the intuitive phrase “the previous level opens more possibilities.”

This must be split into two notions.

## 16.1 Candidate configuration space

If level \(n\) has \(m_n\) reusable effective unit types and the next level can form ordered pairs using \(r_n\) distinct relation/coupling types, then the number of elementary pair configurations is at least

\[
\boxed{
N_{n+1}^{(2)}=r_nm_n^2.
}
\tag{16.1}
\]

For unordered pairs it is

\[
\boxed{
N_{n+1}^{(2)}
=r_n\frac{m_n(m_n+1)}{2}.
}
\tag{16.2}
\]

Allowing triples and larger composites grows the candidate combinatorial space even faster.

## 16.2 Stable possibility space

But only a subset of candidates are dynamically stable.

Therefore it is **not** mathematically valid to assert without further conditions that

\[
|\mathcal S_{n+1}|>|\mathcal S_n|
\]

for the stable-state sets.

The correct RRG claim to test is:

\[
\boxed{
\text{new stable effective units create new candidate relations and modes that were undefined before those units existed.}
}
\]

Monotonic growth of the number of *stable* organizations is a separate hypothesis.
