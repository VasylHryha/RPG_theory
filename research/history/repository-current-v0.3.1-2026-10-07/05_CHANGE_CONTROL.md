# RRG v0.2 — Research / Change-Control Protocol

This document prevents theory drift.

## A. Research does not redefine the core

Every new paper, example, analogy, equation, or simulation must be classified as one of:

1. **Supports core** — example fits an existing locked statement.
2. **Tests core** — provides a measurable way to challenge a locked statement.
3. **Extension** — adds a hypothesis downstream of the core without modifying it.
4. **Implementation** — one mathematical/mechanical realization of the core.
5. **Counterexample candidate** — appears to conflict and must pass the proof gate below.
6. **Rejected drift** — introduces a narrower or different definition without necessity.

## B. Proof gate before changing a definition

A core definition can change only if this template is completed:

- **Locked statement:** exact quote.
- **Counterexample:** exact physical/mathematical system.
- **Why it fails:** demonstrate why the system cannot fit the current definition.
- **Evidence:** primary literature, experiment, or derivation.
- **Extension test:** show why adding a downstream condition cannot handle it.
- **Minimal revision:** smallest possible edit.
- **Regression analysis:** list every previous example/claim affected.
- **Decision:** accept/reject, with version bump if accepted.

No completed proof gate = no core change.

## C. Examples never become definitions automatically

Examples such as atoms, molecules, stars, cells, DNA, organisms, brains, gravity, or AI illustrate the core. None of them may be used to narrow the core unless a proof-gate contradiction is established.

For example:

- A multicellular organism made from differentiated cells is **not** an edge case because RRG never requires identical components.
- A radioactive nucleus is **not** an edge case because RRG stability never meant permanence.
- A stationary field configuration is **not** automatically an edge case because RRG mode structure is broader than a visible periodic motion.

## D. Mathematics is subordinate to the locked meaning

A mathematical model is a candidate realization, not a new definition.

- Lyapunov/Floquet criteria may test a particular form of stability but do not redefine RRG stability.
- A lifetime threshold may be useful operationally but cannot define existence or stability.
- A coarse-graining threshold may identify useful effective units but cannot redefine "scale".
- Requiring the same microscopic equation at every scale is an optional strong hypothesis, not the RRG core.
- An effective action \(\Gamma\), spectral operator, Koopman spectrum, RG flow, etc. may model parts of RRG but cannot become the ontology by default.

## E. Research objective

Research should answer:

> Does the locked geometry↔mode framework generate correct predictions, useful reductions, or new unifying relations across multiple domains?

It should **not** continuously rewrite the question until every example fits.
