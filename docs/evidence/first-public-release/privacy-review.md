# First-test static artifact privacy scope

Available scoped review is accepted in
../github-pages-rebind/first-release/acceptance/rights-privacy-review.md:
75 selected readings, original approved downloads, explanatory ZIP, attribution,
dedicated public contact and licensed research content; no analytics/accounts,
remote scripts, private history, administrative receipts, Rider files or journal
PDFs in the output. Existing exact source/display decisions remain intact.

The owner now explicitly authorizes publication of that test website on the
already-public named repository. policy.repositoryFiles selects engineering
files for the shared repository screen; their contents are screened for concrete
secret patterns before deployment. Research disclosure is limited to the already
approved 75-page manifest and exact selected original downloads, and the fresh
shared output auditor must pass before any upload. This is scope-specific
website/export review, not a claim that the entire existing public source
repository/history has independent human privacy approval.

No administrative evidence is uploaded to the website or as a public diagnostic
artifact. Only the sealed static directory becomes the Pages artifact. Retained
local audit/seal copies are ignored by Git and excluded from public output.
