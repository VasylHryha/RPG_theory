# RRG v0.2 — Drift Repair Changelog

This version does not claim a new theory revision. It repairs places where explanatory/research material silently narrowed the already-agreed core.

## Corrected drift

- **Stability:** restored to geometry↔mode self-consistency for however long the configuration exists. Perturbation recovery and lifetime are tests/properties, not the definition.
- **Higher-level composition:** explicitly allows heterogeneous lower-level components. Identical duplication is not required.
- **Replication:** demoted from any universal requirement to one possible mechanism.
- **Universality:** removed the requirement that every scale obey the same microscopic/effective equation family. RRG requires the locked structural relation; same-equation closure is only a stronger optional result.
- **Scale:** operational modelling criteria no longer redefine scale.
- **Mathematics:** equations are marked candidate implementations/tests and cannot redefine the ontology.
- **Forces/gravity/background:** clearly classified as extensions to prove, not locked conclusions.
