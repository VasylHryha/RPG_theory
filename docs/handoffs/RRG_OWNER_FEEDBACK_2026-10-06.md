Each entry shows:

- a **reading level**: Everyone · Some background · Technical;

- **A–Z key terms** (background, coarse-graining, geometry, mode, recursion,

- Each glossary entry links back to the concept page that defines it.

**Every page then shows its place in the book:** "Part II › Chapter 7.3 —
Star", plus "← Previous · Contents · Next →" links at the bottom, like turning
pages.

**About hover descriptions (research finding: improved approach).**
- **Hover alone does not work for everyone.** Phones and tablets have no hover,
  and keyboard users need focus support. Accessibility rule WCAG 1.4.13 requires
  hover/focus pop-ups to be dismissible, hoverable and persistent. Pure-CSS
  tooltips fail this, and meeting it normally needs JavaScript.
- **The site currently forbids page scripts** (the output auditor allows only the
  search script).
- **Proposed solution:** always show the one-line description (small, muted
  text) under each title, so it works everywhere. On a desktop, hovering or
  focusing a row highlights it. A small "more" toggle (works without
  JavaScript) opens a longer summary, type, level and related pages.
- **Option if the owner still wants true pop-up hover cards:** add one small,
  reviewed script for accessible hover/focus cards. This requires an approved
  change to the site's no-script rule.

**Further options to consider:**
- A visual **map view** of the same contents: the ladder plus the four sections,
  drawn as a diagram with links.
- **"Read the whole book"**: one printable/PDF edition in contents order.

Sources consulted for the hover finding: WCAG 1.4.13 explanations
(wcag.com, DAISY Knowledge Base, BOIA, Pearson accessibility component library).

### 10.1 Owner refinement: the full cycle (6 Oct 2026)

**Owner:** a resonator **reproduces itself, or transforms the environment** to
increase the probability of similar things appearing. Its **geometry becomes
the next building blocks** and starts **creating new resonance**.

**The cycle, which matches the sources:**

```
resonance ⇄ shape (geometry)
        ↓  they hold each other
    RESONATOR (a stable thing)
        ↓  it spreads: copies itself, or changes its surroundings so that
        ↓  similar things become more likely
    BUILDING BLOCKS of a bigger shape
        ↓  the bigger shape carries a NEW, collective resonance
    … the same cycle again, in a different shape, at the next level
```

**Sources:**
- resonance ⇄ shape: core §3; 01 §1.
- Resonator / stability: core §4.
- Spreading: 01 §9 "persistent organization propagates". The same structure
  recurs when conditions recur; chemistry catalyses compatible structures;
  biology templates and reproduces (DNA). Also 04 §10: differential persistence;
  "some spread".
- Changing surroundings: 04 §4, §11.
- Building blocks and new collective resonance: 01 §4 ("collective mode that no
  single part possesses"); core §5.

**Honesty notes to keep visible:**
- Spreading is a *possible* way, not a required step (core §9).
- Influence on the environment needs suitable coupling and resources. It can
  fail, and the most stable thing does not always win (04 §8, §10).

**Site consequence:**
- The home page shows this **cycle as a simple picture**: "the rules".
- The **ladder** then shows the same cycle taking a different shape at each
  level.
- Each ladder step is tagged with what happened there: spreads/recurs, changes
  surroundings, or becomes a building block.
